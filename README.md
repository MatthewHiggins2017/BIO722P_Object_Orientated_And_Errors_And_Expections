# Object Oriented Programming, Errors and Exceptions

Classes, instances, inheritance and polymorphism, followed by runtime errors and exception handling.

## Notebooks

- [Object Oriented Programming, Errors and Exceptions](Object_Oriented_Programming_and_Errors_and_Exceptions.ipynb): combined lessons, with object oriented programming first and errors and exceptions second.
- [OOP and Exceptions Exercises](OOP_and_Exceptions-Exercises.ipynb): exercises in the same topic order.
- [Additional exercises](Additional_exercises.ipynb)
- [Biopython minimal sampler](Biopython_minimal_sampler.ipynb)


## Supporting Files

Keep the notebooks in this directory so that the `students.py` module, sequence files and audio files remain accessible at their existing relative paths. Sequence data are in `data/`, with an additional `P04637.fas` in this directory. Audio files are in `media/`.

Install the declared dependency with `pip install -r requirements.txt` in your Jupyter environment. The embedded video controls also use `ipywidgets` from that environment.


The original materials are available in the [Object Oriented Programming repository](https://github.com/fsmeraldi/c4s-objects) and the [Errors and Exceptions repository](https://github.com/fsmeraldi/c4s-exceptions). Their Binder links launch the original repositories, not this merged directory.
